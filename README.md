# Character.ai-persona-exporter
The browser extension that let's you download your personas as png with metadata/txt/png+txt

Okay, so... I created this source of my extension for people with doubt. It's not a virus or anything.
This extension was based on "Character export" extension, that let's you export personas! Also can help the persona you are searching for not via name but description!

Full instruction was written in original post on reddit: https://www.reddit.com/r/CharacterAI_CAITools/s/CV3ZnJp1Um

1. Just download files in one folder: folder/files (press on "CODE" button, download zip and unzip out the folder)
2. Go to the extension manager and turn on "Developer Mode", drag the folder and drop into tab
3. Turn it on and refresh the personas' page

DONE! Now you have icon on top right, click on it and you have all the options and intructions how it works... or whatever... Use however you want, export? Can. Search persona by description? Also yeah
